# Morkvær – webversjon

Spillbar webversjon av *Morkvær*, et etterforskningsspill med kosmisk skrekk laget i Godot 4.
En ung distriktslege kommer til fiskeværet Morkvær i mørketida, desember 1925.

**Spill her:** https://audunt.github.io/morkvaer-web/

Dette repoet inneholder bare det ferdige bygget. Det lages av `tools/export_web.sh` i
hovedrepoet og legges inn her. Lagring og innstillinger lagres i nettleseren. Lyden
starter når du har trykket på noe.

Taster: piltastene eller WASD for å gå, E for å undersøke, M for kart, N for notatbok og
Esc for meny.
